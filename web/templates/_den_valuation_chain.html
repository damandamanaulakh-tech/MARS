What it does. For each name below: locks the latest audited year (period end, publication date, currency — the US-dollar trap for ADR names is converted at the period-end rate and labelled, never silently), picks the valuation route from the sector-method table (unmapped names read UNDECLARED, never forced), reconciles the share count, strips one-offs from reported profit (checked against the audited normalised line), scores earnings quality, runs your Tata Tech scenario model as three cases (downside / base / upside) and prints the justified range per route, then the verdict: attractive · watch · unattractive · insufficient. Not a trade permission — the engine still buys on the momentum score.
Coverage. Statements exist for the {{ chain.n_statements }} Nifty-200 names fetched 2026-08-09 (+ the monthly refresh); any other name reads DATA_NEEDED until the batch fetch you have not yet approved runs. Peer multiples are derived: the median of the same route among those names (ASSUMED until you give peer groups). Macro rows of the P/E bridge we do not store (repo, CPI, GDP, Brent) count 0 and are listed as DATA_NEEDED on each row.
