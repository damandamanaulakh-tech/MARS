ℹ️ What is this page asking for?

The engine auto-detects drawdown escalations, regime switches, and kill-switch triggers — but it can only push those to you if you've told it where. This page configures the destination.

Slack (recommended, free, easiest):

  1. Open Slack → your workspace → "Apps" → search "Incoming Webhooks" → Install.
  2. Pick a channel (e.g. #am07-alerts) → Copy the webhook URL it gives you.
  3. In Render → your service → "Environment" → add env var SLACK_WEBHOOK_URL with that value → Save → service auto-redeploys.
  4. Come back here and hit SEND TEST — you should get a message in Slack within 2 seconds.

Email (optional, SMTP):

  • ALERT_EMAIL_TO — your inbox (e.g. you@gmail.com)
  • SMTP_HOST — smtp.gmail.com (Gmail) / smtp.sendgrid.net / your provider
  • SMTP_PORT — 587 (TLS, default)
  • SMTP_USER + SMTP_PASS — Gmail needs an app-password, not your real password

Don't put credentials in this UI or commit them — only in Render's Environment tab. Same-fingerprint dedupe (60 min) means you won't get spammed if the same drawdown level persists across scans.
