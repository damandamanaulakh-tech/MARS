What it does. Takes a dated standalone target (normalised earnings × justified P/E — typed here until the sequence produces it) and shows what the context says about it today: the sector leg both ways (your 1:1 rule beside the stock's measured β), the rates leg through the discount rate, a sentiment margin that only widens the buy discount, and a verify split of the stock's actual move into the sector part and the stock-specific residual. A residual beyond ±{{ val.assumed.rerun_residual_pct | round(0) | int }}% flags the standalone valuation for a re-run (your event loop).
Formulas. 1:1 = target × (1 + sector move) · measured = target × (1 + β × sector move), β = slope of daily returns on the sector over the last {{ val.assumed.beta_window_days | int }} sessions (at least {{ val.assumed.beta_min_obs | int }}) · rates multiplier = (rthen − g) / (rnow + shift − g), r = 10-year yield + equity risk premium · buy-below = context target × (1 − discount), discount = {{ val.assumed.base_buy_discount_pct | round(1) }}% + {{ val.assumed.fear_step_pp | round(1) }} points per fear gauge ON.
Sensitivity today. {% if val.sensitivity_per_pp is not none %}At a 10-year yield of {{ val.rate_now_used | round(2) }}%, ERP {{ val.assumptions.erp | round(1) }}% and growth {{ val.assumptions.growth | round(1) }}%, one extra point on the rate (or of inflation) moves every context target {{ val.sensitivity_per_pp | round(1) }}%.{% else %}DATA_NEEDED — no 10-year yield to compute the sensitivity.{% endif %} 10-year yield file: {% if val.bond_last %}last row {{ val.bond_last[0] }} at {{ val.bond_last[1] | round(3) }}% — type today's yield below to replace it{% else %}unreadable{% endif %}.
Sector indices. Indian only, as you chose: {% for s, i in val.sector_index_map.items() %}{{ s }} → Nifty {{ i }}{% if not loop.last %} · {% endif %}{% endfor %}; realty names → Nifty Realty. Any other sector reads Nifty 50 and says so. Global sector indices: DATA_NEEDED, no free feed reaches the box.
ASSUMED, not measured: ERP, growth, the {{ val.assumed.base_buy_discount_pct | round(0) | int }}% base discount and its {{ val.assumed.fear_step_pp }}-point steps, the ±{{ val.assumed.rerun_residual_pct | round(0) | int }}% re-run band. The sentiment gauges widened the margin only — the 09-09 and 09-29 studies measured none of them as a predictor of the next move.
